# 你好，世界

这是你的第一篇文章。这个博客是**纯静态**的，部署在 GitHub Pages 上，但你依然可以通过 `admin.html` 后台在线管理它。

## 它是怎么工作的

- 文章以 Markdown 文件存放在仓库的 `posts/` 目录
- `posts.json` 是文章索引（标题、日期、摘要）
- 后台通过 GitHub API 直接提交文件到仓库，触发 Pages 重新部署

## 支持的语法

代码块：

```js
console.log("hello blog");
```

> 引用、**加粗**、*斜体*、列表、分割线……标准 Markdown 都支持。
